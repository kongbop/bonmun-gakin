# 본문 각인

영어 3·4단원 본문 암기 훈련 앱. 휴대폰 홈 화면에 설치할 수 있고, 한 번 열어 두면 인터넷 없이도 동작한다.

단계: 본문 읽기 → 레벨 1~3 (빈칸) → 레벨 4 (해석 보고 문장 쓰기) → 레벨 5 (힌트 없는 빈칸) → 어법 문제. 틀린 단어는 복습 목록과 단어장에 모인다.

## 설치

- 안드로이드 (크롬): 사이트 접속 → 오른쪽 위 메뉴 → 앱 설치 또는 홈 화면에 추가
- 아이폰 (사파리): 사이트 접속 → 공유 버튼 → 홈 화면에 추가

## 파일

- `index.html`: 앱 전체 (본문, 해석, 단어 뜻, 어법 문제 포함)
- `sw.js`: 오프라인 지원. 앱 파일을 저장해 두고, 온라인일 때 새 버전을 받아 다음 실행부터 반영한다.
- `manifest.webmanifest`, `icons/`: 홈 화면 설치용 이름과 아이콘

기록(깬 레벨, 복습 목록, 단어장)은 기기 브라우저에 저장되며 다른 기기와 공유되지 않는다.
