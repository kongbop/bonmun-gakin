# 본문 각인

영어 3·4단원 본문 암기 훈련 앱. 휴대폰 홈 화면에 설치할 수 있고, 한 번 열어 두면 인터넷 없이도 동작한다.

단계: 본문 읽기 → 레벨 1~3 (빈칸) → 레벨 4 (해석 보고 문장 쓰기) → 레벨 5 (힌트 없는 빈칸) → 어법 문제. 틀린 단어는 복습 목록과 단어장에 모인다.

## 설치

- 안드로이드 (크롬): 사이트 접속 → 오른쪽 위 메뉴 → 앱 설치 또는 홈 화면에 추가
- 아이폰 (사파리): 사이트 접속 → 공유 버튼 → 홈 화면에 추가

## 파일

- `index.html`: 앱 전체 (본문, 해석, 단어 뜻, 어법 문제 포함)
- `sw.js`: 오프라인 지원. 앱 파일을 저장해 두고, 온라인일 때 새 버전을 받아 다음 실행부터 반영한다.
- `manifest.webmanifest`, `icons/`: 홈 화면 설치용 이름과 아이콘

기록(깬 레벨, 복습 목록, 단어장)은 기기 브라우저에 저장되며 다른 기기와 공유되지 않는다.

## 10월 모의고사 시험 범위 학습 (`mock10/`)

2026년 10월 고2 모의고사 중 학교 시험 범위(21~24, 30~34, 36, 37, 39, 41~42번) 학습 페이지. 주소 끝에 `mock10/`을 붙여서 연다.

- 지문별 학습: 핵심 정리, 실전 문제, 본문 암기(끊어 읽기·뜻 가리기·단어 눌러 단어장에 넣기), 어법 선택, 틀린 곳, 서술형, 어휘, 변형 문제
- 교과서 3·4과 파트에는 ‘레벨 암기’ 탭이 있다: 본문 각인과 같은 레벨 1~5(빈칸 20% → 50% → 전체+첫 글자 → 해석 보고 쓰기 → 힌트 없는 전체 빈칸). 틀린 단어는 파트별 복습 목록에 모인다(내 단어장에는 본문 암기에서 직접 누른 단어만 들어간다).
- 변형 문제: 시험 유형(제목, 문맥상 낱말, 밑줄 의미, 의미가 다른 하나, 빈칸, 순서, 삽입, 요약)과 서술형
- 섞어 풀기, 오답 노트(한 번 맞히면 빠짐), 내 단어장

`mock10/index.html` 한 파일에 모든 내용이 들어 있다. 기록(오답 노트, 단어장)은 이 기기 브라우저에 저장되며, Claude에서 열었을 때의 기록과는 따로 저장된다.
